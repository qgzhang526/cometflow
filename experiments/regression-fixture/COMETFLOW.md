# 项目使命

## 技术栈

| 维度 | 值 |
|------|-----|
| 前端 | 无 |
| 后端 | TypeScript |
| 数据库 | 无 |
| 缓存 | 无 |
| 测试框架 | vitest |
| 构建工具 | tsc |

## 运行环境

| 维度 | 值 |
|------|-----|
| 操作系统 | Linux |
| 部署方式 | 本地 |
| 语言版本 | Node 22+ |
