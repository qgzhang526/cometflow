# core capability

2048 游戏核心引擎：纯 TypeScript 实现，不依赖渲染/输入库。

## FR-2048-001 棋盘初始化

棋盘为 4×4 网格，初始恰好有 2 个 tile；新 tile 数值 90% 为 2、10% 为 4；随机源可注入。

## 验收

- A001：初始化后棋盘存在 2 个 tile 且位置随机
- A002：初始化后棋盘存在至少一个空位
- A003：注入固定种子时初始化结果可复现

## FR-2048-002 移动与合并

支持上/下/左/右四个方向移动；相同 tile 一次移动内只合并一次；合并分值累加到总分。

## 验收

- A010：四个方向移动后 tile 正确塌缩与合并
- A011：一次移动内每个 tile 至多参与一次合并
- A012：合并分值正确累加到总分
- A013：无效移动（棋盘不变）不新增 tile、不加分

## FR-2048-003 胜负判定

出现 2048 tile 时判定获胜但可继续；无空位且无相邻可合并 tile 时判定游戏结束。

## 验收

- A020：出现 2048 tile 时游戏标记为获胜且可继续
- A021：无空位且无相邻可合并 tile 时游戏结束
- A022：游戏结束后任意移动不再改变棋盘
