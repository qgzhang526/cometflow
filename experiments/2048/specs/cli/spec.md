# cli capability

终端交互玩法：ANSI 渲染、键盘输入、对局控制。

## FR-CLI-001 启动与渲染

启动后渲染 4×4 棋盘与当前分数；渲染支持非 TTY 环境输出固定格式快照。

## 验收

- A101：启动即渲染棋盘与分数
- A102：非 TTY 模式下输出可解析的棋盘快照
- A103：ANSI 输出在非 TTY 模式下自动禁用

## FR-CLI-002 输入与控制

支持 WASD 与方向键；q 退出；r 重开。

## 验收

- A110：WASD 与方向键均能驱动移动
- A111：q 退出对局，r 立即重开
- A112：非法输入被忽略且不崩溃
- A113：无效移动给出提示且棋盘不变

## FR-CLI-003 对局流程

游戏结束后展示最终分数，并提供重开/退出选择。

## 验收

- A120：游戏结束时显示最终分数与选择
- A121：重开后棋盘重新初始化
